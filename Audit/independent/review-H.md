## Details for non-faithful items

### 1. `doeblin` (MarkovChain.lean): WEAK
Hypothesis: `∀ z z', ε ≤ Q z z'` with ε > 0, meaning every transition probability is bounded below. That is a one-step,
all-entries strict positivity condition. The textbook conditions are much weaker:
- SLP Thm 11.4 needs only that some power Qᴺ has a column with all entries positive. Uniqueness follows, and so does
  convergence when the chain is aperiodic.
- Doeblin / SLP Condition M needs an N-step minorization Qᴺ(z,·) ≥ ε φ(·).

Counterexamples (sanity test 1):
- `Q = [[0,1],[1/2,1/2]]` is irreducible and aperiodic, has Q² > 0 and unique invariant (1/3, 2/3), and converges
  geometrically. `doeblin` cannot be applied because Q₀₀ = 0.
- `Q = [[1/2,1/2],[0,1]]` has an absorbing state and a positive column, with unique invariant (0,1). `doeblin` again
  cannot be applied.

The N-step all-entries version follows from `doeblin` applied to Qᴺ plus `exists_invariant`, but that corollary is not
stated. The single-column/minorizing-measure version cannot be recovered this way. The theorem is named after a
condition it does not formalize.

### 2. `StochDynProg.exists_stationary` and `StochSavings.exists_stationary`: WEAK / VACUOUS-RISK
These state only that some invariant probability measure exists for the optimal-policy kernel on the compact set S × Z.
In any growth-type instance with f(0) = 0, zero capital is absorbing: Γ(0,z) = {0} forces g(0,z) = 0 (sanity test 3).
The measure δ₀ ⊗ π_Q is then invariant, so the theorem is true for a degenerate reason. `brockMirmanExample` is exactly
this case.

The canonical Brock–Mirman result (SLP §13.3, Thms 12.12 / 13.?) is stronger. It gives a unique invariant measure on an
ergodic set [k_min, k_max] bounded away from 0, with weak convergence from every k₀ > 0. None of that is stated.

For income-fluctuation models the canonical result (LS ch. 18, Aiyagari 1994) also includes uniqueness through
monotonicity and a mixing condition.

### 3. `policy_of_optimal` (StochasticPlan.lean): WEAK
SLP Thm 9.5 / the stochastic analogue of 4.5 says: if a plan σ is optimal from s, then σ_t(zᵗ) ∈ G(x_t, z_t) for
μᵗ-almost every history, at every date t. The Lean statement gives only `σ [] ∈ P.policy s`. Optimality of the
continuation `shift σ z` for z with Q(s₂,z) > 0 is not stated either, so the date-t claims cannot be obtained by simply
reapplying the theorem. The missing target is written down in sanity test 6.

### 4. `abs_payoffN_succ_sub_le` (StochasticPlan.lean): MISMATCH (unreadable)

Check whether the original source has a conclusion that the stripping removed, for example a `|…|` expression mistaken
for a comment.

### 5. `ConcaveRet` / `value_concave` (StochasticConcavity.lean): documented deviation plus WEAK conclusion
SLP Assumption 9.11 requires strictness of F(·,·,z) when x ≠ x', and concludes that v(·,z) is strictly concave and g is
continuous and single-valued (Thm 9.8). This file instead requires strictness when x = x', y ≠ y', and concludes only
that v(·,z) is weakly concave.

The two hypotheses are not nested:
- F(x,y) = −x² + y satisfies SLP's condition but fails `ConcaveReturnStrictInChoice` (sanity test 4).
- F(x,y) = −y² satisfies `ConcaveReturnStrictInChoice` but not SLP's condition.

So the SLP version of Thm 9.8 is not covered. The RCK and savings applications satisfy both, so nothing downstream is
broken.

Coverage gap: the task asks for SLP 9.7–9.10. Monotonicity of v(·,z) (Thm 9.7), Benveniste–Scheinkman (Thm 9.10) and
monotonicity in z (Thm 9.11) are not stated anywhere in the target files.

### 6. `RCKModel.optimal_capital_converges` (Ramsey.lean): WEAK (superseded)
The conclusion is `∃ kinf, g kinf = kinf ∧ planOf g k₀ → kinf`. Because g 0 = 0 always (sanity test 2), kinf can be 0.
Without Inada, when f'(0) ≤ 1/β, the optimal path really does go to 0. So the statement is correct but has little
content.

The headline `RCKModel.global_convergence` (RamseyGlobal.lean) fixes this. It gives the unique k* > 0 with
β f'(k*) = 1, g k* = k*, and convergence from every k₀ > 0. This check passes.

### 7. `RCKModel` / `StochSavings` bounded-utility restriction: documented deviation
`u : ℝ → ℝ` must be `Continuous` on all of ℝ. That rules out log utility (sanity test 5: `Real.log` is not continuous at
0 in Mathlib) and CRRA with σ ≥ 1. Those are the textbook Brock–Mirman specification (`BrockMirman.lean` handles log
separately and deterministically) and the LS ch. 18 benchmark. The √-utility examples work.

The RCK model is the discrete-time, full-depreciation one-sector model (SLP §2.1/§6.1), not the continuous-time Ramsey
model of Acemoglu ch. 8. That is acceptable, but the naming should say so.

### 8. `StochSavings` (StochSavings.lean): significant deviation and coverage gap
- Assets are forced into [0, k̄] for an arbitrary k̄. In `aiyagariExample`, cash on hand reaches 1.5 while savings are
  capped at 1, so the cap may bind and change the optimal policy. In LS ch. 18 the upper bound is *derived* from
  β(1+r) < 1 and is not imposed.
- There are no prices. h is an abstract concave function, so there is no r, no w, no borrowing limit and no market
  clearing. "Aiyagari" therefore refers to the household block only, with r = 0.
- None of the canonical results are stated: the asset bound, divergence when β(1+r) ≥ 1, a unique stationary
  distribution, continuity or monotonicity of aggregate savings A(r), or the equilibrium r < 1/β − 1.
